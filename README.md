# 🦷 DentalControl

DentalControl is a desktop application for dental clinic management built with WPF and MVVM.

## 🚀 Technologies

- .NET 8
- WPF
- MVVM
- Entity Framework Core
- SQLite

## 📋 Features

- Patient Management
- Medical Records
- Consultations
- Treatments
- Prescriptions
- Medical Certificates
- Billing
- Reports

## 🏗 Architecture

This project follows the MVVM architectural pattern and applies software engineering best practices, including:

- Entity Framework Core
- Repository Pattern
- Service Layer
- Dependency Injection

## 📁 Project Structure

```text
DentalControl
│
├── Data
├── Models
├── Repositories
├── Services
├── ViewModels
└── Views
```
